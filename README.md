# Scanly 📄

App iPhone et iPad (SwiftUI + VisionKit + Vision) pour scanner ses papiers : détection automatique des bords, texte reconnu sur l'iPhone et **recherchable**, PDF recherchables et protégés par mot de passe, signature, fusion, verrouillage Face ID. 5 langues, Liquid Glass.

**Un scanner… sans abonnement.** Toutes les fonctions, pas de filigrane, achat unique. Même design, même achat intégré et même charte que Swipe Photos et Subs : *que du vrai, paiement unique, pas de blabla.*

👉 **Tout est dans le dossier [`Scanly/`](Scanly/)** : projet Xcode prêt à ouvrir, icône, textes App Store en 5 langues.
👉 **Le guide complet : [`Scanly/README.md`](Scanly/README.md)**

📦 **Téléchargement direct : [`Scanly.zip`](Scanly.zip)** → clique dessus puis sur l'icône de téléchargement (« Download raw file »).

Ou : bouton vert **Code → Download ZIP** sur GitHub (en étant sur cette branche), puis ouvre `Scanly/Scanly.xcodeproj`.
